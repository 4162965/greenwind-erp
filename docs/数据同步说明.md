# 数据同步说明

本仓库默认不提交本地运行数据库，避免把临时数据、缓存和测试库混进代码。

本次为了把家里开发机的数据同步到 NAS/服务器，已额外提交一份明确的数据快照：

```text
deploy/seed/greenwind.seed.20260820.db
```

这份快照来自：

```text
backend/greenwind.db
```

它包含当前本地开发测试数据，例如：

- 商品：20 条
- 客户：5 条
- 员工：5 条
- 项目：5 条
- 采购、配送、合同、应收、发票、车辆、养护等测试数据

## NAS/服务器导入方式

`docker-compose.nas.yml` 已加入首次导入逻辑。

容器启动并拉取最新代码后，如果检测到：

```text
/repo/deploy/seed/greenwind.seed.20260820.db
```

且服务器还没有导入标记：

```text
/data/.greenwind_seed_20260820_imported
```

就会执行：

1. 如果服务器已有 `/data/greenwind.db`，先备份为：

```text
/data/greenwind.before-seed-20260820-日期时间.db
```

2. 把本地快照复制为服务器运行数据库：

```text
/data/greenwind.db
```

3. 写入导入标记，避免以后每次重启都重复覆盖。

## 如果需要重新强制导入

进入 NAS 的 Docker 数据卷，删除：

```text
/data/.greenwind_seed_20260820_imported
```

然后重启项目即可重新导入。

注意：重新导入会再次覆盖服务器当前数据库，但会先自动备份旧库。
