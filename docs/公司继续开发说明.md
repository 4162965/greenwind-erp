## 3. NAS 一键部署

在绿联 NAS 或飞牛 NAS 的 Docker 项目里，直接使用仓库根目录的：

- `docker-compose.nas.yml`

这个文件不要求 NAS 上提前有项目目录。启动后会自动从 GitHub 拉取：

```text
https://github.com/4162965/greenwind-erp.git
```

以后本地开发完成后：

1. 把代码提交并推送到 GitHub。
2. 到 NAS 的 Docker 项目里重启 `lvfeng` 项目。
3. 后端容器启动时会自动 `git pull` 拉最新代码。

## 4. 公司电脑继续开发

公司电脑如果要直接改代码：

1. 安装 Git。
2. 安装 Node.js 20。
3. 安装 Python 3.11。
4. 克隆仓库：

```bash
git clone https://github.com/4162965/greenwind-erp.git
cd greenwind-erp
```

启动后端：

```bash
cd backend
pip install -r requirements.txt
python -m app.seed
uvicorn app.main:app --host 0.0.0.0 --port 8010
```

启动前端：

```bash
cd frontend
npm install
npm install element-plus @element-plus/icons-vue
npm run dev -- --host 0.0.0.0
```
