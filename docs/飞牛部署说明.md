# 飞牛 NAS 局域网测试部署说明

这个部署方式用于公司同事在局域网内测试绿风管理软件。

## 访问方式

部署成功后，在公司局域网浏览器打开：

```text
http://飞牛NAS内网IP:5173
```

后端接口端口：

```text
http://飞牛NAS内网IP:8010
```

## 第一次部署

1. 在飞牛 NAS 安装 Docker / Docker Compose。
2. 从 GitHub 拉取项目源码。
3. 进入项目目录。
4. 复制环境变量文件：

```bash
cp .env.example .env
```

5. 修改 `.env`：

```text
APP_SECRET=改成一串随机字符
FRONTEND_ORIGIN=http://飞牛NAS内网IP:5173
FRONTEND_PORT=5173
BACKEND_PORT=8010
```

6. 启动：

```bash
docker compose --env-file .env -f docker-compose.prod.yml up -d --build
```

## 更新系统

以后我这边改完代码并上传 GitHub 后，在飞牛项目目录执行：

```bash
git pull
docker compose --env-file .env -f docker-compose.prod.yml up -d --build
```

## 数据位置

数据库会保存在项目目录：

```text
data/greenwind.db
```

这个目录不要删除。建议定期备份 `data` 文件夹。

## 注意

- GitHub 不上传数据库文件。
- `data/greenwind.db` 是飞牛上的测试数据。
- 正式运行前要修改默认管理员密码和 `APP_SECRET`。
